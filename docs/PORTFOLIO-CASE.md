# Shapecheck — текст для кейса

Разработал Shapecheck — локальный стенд проверки JSON-ответов по контракту JSON Schema draft-07 на React и TypeScript. Инструмент показывает точные пути ошибок, хранит положительные и отрицательные примеры и экспортирует переносимые Node-тесты, которые можно запускать без установки зависимостей. Для недоверенных схем использовал AJV в отдельном worker, ограничения входных данных и раздельные таймеры загрузки и проверки; данные остаются локальными, а сохранение включается явно. Проект опубликован на GitHub Pages и проверен unit-тестами, E2E, запуском реального экспорта и независимыми security и UX/a11y ревью; поддержка ограничена явно описанным безопасным подмножеством draft-07.
